

\begin{lstlisting}[language=bash]
brew install openfpgaloader
\end{lstlisting}

Open FPGA loader is used to take the bitstream file and load it over to a board. 
It can be built from source and the online install guide for the tool includes special Mac instructions for doing just that; however, 
luckily it is already available as a homebrew install. 
Run the above command in your terminal and you will have openfpgaloader ready to run. 
This unfortunately does not accept HDL files as input; however, 
you can directly load bitstream files from the command line.

\begin{lstlisting}[language=bash]
 openFPGALoader -b basys3 your_bitstream.bit
\end{lstlisting}

If you have a bitstream file handy (Potentially from one of your classmates) then you can test openFPGALoader now using the above command.
