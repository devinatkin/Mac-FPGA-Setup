You're going to need to install the Mac Homebrew tool. 
For those of you unfamiliar with it, Homebrew is an open source package manager for Apple computers. 
This makes installing software and its dependencies much simpler, 
in this case given we are installing several pieces of software this will let us do it in a single step.

\begin{lstlisting}[language=bash, columns=fullflexible]
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
\end{lstlisting}
    

Run the above command in your terminal to install homebrew. 
This will download the install script and execute it. 
If you run into any issues follow the link for the most up to date instructions on how to install homebrew: \href{https://brew.sh/}{https://brew.sh/}.
